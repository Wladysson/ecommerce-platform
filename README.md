<h1 align="center">Vitrine de Produtos</h1>

## Sobre o Projeto

A plataforma permite que usuários autenticados cadastrem produtos e que usuários não autenticados visualizem os produtos publicados e seus detalhes.

---

## Funcionalidades

### Usuário
- Login e autenticação
- Visualização de produtos cadastrados
- Visualização de detalhes do produto no carrinho

### Admin / Usuário autenticado
- Cadastro de produtos
- Informações do produto:
  - Nome
  - Descrição
  - Preço
  - Categoria
  - Imagem
